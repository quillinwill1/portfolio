Make this portfolio your own.

A one-page layout designed to reproduce with ordinary text boxes, columns, background colors, and buttons.

Download the complete website kit · Download the editable project copy

Option 1: Recreate it in Google Sites

  1. Create a blank site. Use your name as the site title and a simple header. Add Work, About, and Contact navigation using sections or separate pages if section links are unavailable.
  2. Set a light ivory background, dark navy text, and a restrained rust accent. Use a serif heading font and a simple sans-serif body font.
  3. Add the headline, introduction, and two buttons. Put AWS, Glia, and ManyChat in a three-column row beneath it as plain text.
  4. For each project, insert a two-column layout. Use a colored text panel or screenshot on the left and the category, title, description, and artifact buttons on the right.
  5. Use collapsible text for “Project context & my role.” If your editor does not support this, use ordinary text below each project.
  6. Add two columns for Glia and ManyChat. Then add the About text, career timeline, and contact buttons.
  7. Use the downloaded copy as your starting point. The exact complete live-page text is also in index.html, which opens in a browser for copying.
  8. Preview the mobile version. Stack project columns, keep headings readable, and verify every external link while signed out.

Option 2: Use the exact website

Unzip the kit and open index.html in a browser. It is a complete website with its styling embedded, no installation or build step required. Upload index.html to a static website host to use the exact design. Keep this guide and the copy file for editing.

Before replacing your existing site

  • Confirm your role descriptions and dates. The current copy uses your October 2026 resume and the projects you supplied.
  • Open both Wickr videos and confirm their titles. Their content could not be retrieved during research, so the portfolio uses neutral video labels.
  • Customer statistics are attributed to published stories; they are not presented as results caused by your marketing work.
  • Use screenshots or original assets only when you have permission. This version uses editable text panels so it does not depend on image files.
  • For stronger case studies, add one specific strategic decision and a documented marketing outcome to each project.
  • Google Sites can approximate the layout with built-in elements; hosting the supplied HTML reproduces it exactly.
